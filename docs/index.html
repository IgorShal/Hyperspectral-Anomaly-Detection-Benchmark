Runtime by scene

Inference starts with the shared scene cube in CPU memory and a model ready for prediction. It includes method-specific input preparation and GPU transfers where applicable, and ends when the complete score map is on the CPU. The table reports the median of five runs after one warm-up.

GT-HAD and SM-HAD. Each timed run uses frozen weights and includes a preliminary reconstruction, fresh patch matching (CMM), and a final pass. ROC AUC uses the correspondences obtained during training on the evaluated scene.

ROC AUC checks are timed separately and include evaluation passes, metric calculation, and checkpoint handling where applicable. Mean time per optimizer step is training time divided by the number of optimizer updates. Training fields are blank for RX, LRX, and AED. SM-HAD training time covers all three seeds. Settings and sources

Budgets apply per TIFF scene. RX, LRX, and AED operate without training epochs. AED and LRX were calibrated on HAD12, HAD13, San_Diego, and Hydice_Urban, which are included in the benchmark.
